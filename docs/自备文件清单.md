# 自备文件清单

仓库只保存脚本、译文和人工整理表。原盘、字体和本地生成的资源树都不入库，克隆后需按下表补齐。

## 1. 必需：日版原盘

| 路径 | 说明 |
| --- | --- |
| `roms/Wachenroeder (Japan).cue` | 单 BIN 五轨，TRACK 01 为 MODE1/2352 数据轨，TRACK 02-05 为 AUDIO |
| `roms/Wachenroeder (Japan).bin` | 544,805,520 字节 |

必须自备正版镜像。`roms/Wachenroeder (Japan).chd` 只是对照与校验用的备份，构建读取的是 CUE 与 BIN；原日版 CHD 的 SHA-256 记录在 [README](../README.md)。

由原盘生成 `unpacked/japan`：

```powershell
pwsh -NoProfile -File .\analysis\extract-iso.ps1 `
    -TrackPath "roms\Wachenroeder (Japan).bin" `
    -OutputDirectory .\unpacked\japan
```

## 2. 必需：字体

构建读取以下两款基础字体，由用户自行准备，不随仓库提供。

| 路径 | 字体 | 授权 | 用途 |
| --- | --- | --- | --- |
| `work/fonts/ChillBitmap_16px.ttf` | 寒蝉点阵体 16px | OFL 1.1 或 GPLv2 + 字体嵌入例外 | 主字库，16×16 |
| `work/fonts/fusion-pixel-8px-proportional-zh_hans.ttf` | Fusion Pixel 8px Prop zh-Hans | SIL OFL 1.1 | 紧凑窄字库，8×8 |

Fusion Pixel 见 <https://github.com/TakWolf/fusion-pixel-font>；寒蝉点阵体取 16px 版本，下载后按上表文件名放置。

默认 8×12 构建还需要 `work/fonts/MZPXorig.ttf`（MuzaiPixel，SIL OFL 1.1）。该字体由 `build-chinese-fonts.py` 与 8×12 字库生成流程使用；历史 8×8 模式不要求它，但该模式的字库容量不足以构建当前完整译文。

字体替换后必须重跑构建；字库按固定像素尺寸栅格化，换字体后字形边缘会变。

## 3. 工具链

| 依赖 | 说明 |
| --- | --- |
| Python 3.10+ | 运行 `tools/*.py`，包见 [requirements.txt](../requirements.txt) |
| PowerShell 7（`pwsh`） | 所有 `.ps1` 步骤，`build-full-translation.bat` 会检查 |
| MSVC（`cl` 或 `clang-cl`）+ Windows SDK 10 | 首次构建时编译 `tools/chd-disc-tool.cpp`；`temp/disc-tool/chd-disc-tool.exe` 已存在时跳过 |

```powershell
py -3 -m pip install -r requirements.txt
```

## 4. 快速自查

```powershell
py -3 .\tools\check-assets.py
```

该检查需在首次提取、资源导出和文本目录导出完成后运行；它会检查生成的字表与原始字库。只读检查，缺必需项时列出路径并以 1 退出。
